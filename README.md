## 🤔 为什么做这个导航？

AI 工具爆炸式增长，但大多数导航站广告泛滥、信息过时、不标注要不要花钱、也不告诉你国内能不能直接用。本导航的原则：

- 🟢🟡🔴 **标注价格**：免费 / 免费+付费 / 付费，一目了然
- 🟣 **标注国产**：国内可直接访问的工具单独标记
- ✅ **只收精品**：每个分类只留真正好用的，不做大而全的垃圾场
- 🔄 **持续更新**：AI 工具迭代快，本库跟随更新
